## Что мы будем устанавливать

Чтобы писать и запускать программы на C#, нам понадобятся три вещи:

| Что | Зачем нужно |
| --- | --- |
| **Visual Studio Code**, сокращённо **VS Code** | Редактор, в котором мы будем открывать файлы и писать код. |
| **.NET SDK** | Набор инструментов, который создаёт проекты, собирает код в программу и запускает её. |
| **Расширение C# от Microsoft** | Дополнение для VS Code: даёт подсказки при наборе кода и помогает замечать ошибки. |

Представьте, что вы готовите по рецепту. VS Code — место, где записан рецепт, а .NET SDK — инструменты, с помощью которых по нему можно приготовить блюдо. Расширение C# помогает правильно записать сам рецепт.

**Консольная программа** общается с человеком через текст: выводит сообщения в терминал и при необходимости принимает ввод с клавиатуры. Именно такой проект мы создадим.

## Как выполнять инструкцию

1. Выполняйте шаги по порядку.
2. После каждого действия сверяйтесь с описанием результата.
3. Если появилась ошибка, сначала найдите её в разделе [«Если что-то не получилось»](#если-что-то-не-получилось).

В инструкции встречаются два вида блоков:

**Команда для терминала** — её нужно ввести в терминал и нажать `Enter`:

```powershell
dotnet --version
```

**Код программы** — его нужно написать в файле `Program.cs`:

```csharp
Console.WriteLine("Hello, World!");
```

> [!IMPORTANT]
> Команды и код вводятся в разных местах. Если над блоком написано «в терминале», вводите его в нижнюю панель терминала. Если написано «в файле Program.cs», вводите его в редактор кода.

Когда указано сочетание `Ctrl + S`, удерживайте `Ctrl` и один раз нажмите `S`. Для команд и кода переключайте клавиатуру на английский язык.

## Шаг 1. Установите Visual Studio Code

### Скачайте установщик

1. Откройте браузер.
2. Перейдите на [официальную страницу загрузки VS Code](https://code.visualstudio.com/download).
3. Выберите загрузку для **Windows**. Если предлагаются варианты, выберите **User Installer** — установку для вашей учётной записи.
4. Выберите архитектуру своего компьютера: **x64** для обычного компьютера с 64-разрядным процессором Intel или AMD; **Arm64** — для Windows на ARM.

<details>
<summary>▶ Как узнать архитектуру компьютера</summary>

Откройте **Пуск → Параметры → Система → О системе**. В английской Windows: **Start → Settings → System → About**.

Найдите строку **Тип системы / System type**:

| Что написано | Что скачивать |
| --- | --- |
| Процессор x64 / x64-based processor | **x64** |
| Процессор ARM / ARM-based processor | **Arm64** |

</details>

### Установите VS Code

1. Откройте скачанный файл `.exe`. Обычно он находится в папке **Загрузки / Downloads**; его также можно открыть из списка загрузок браузера.
2. Ознакомьтесь с условиями установки и продолжите кнопкой **Next** — «Далее».
3. Оставьте предложенную папку установки.
4. Если на экране дополнительных настроек есть пункт **Add to PATH**, оставьте его отмеченным. Он позволит открывать VS Code командой `code`.
5. Нажмите **Install** — «Установить», дождитесь окончания и нажмите **Finish** — «Завершить».
6. Откройте **Visual Studio Code** через меню «Пуск», если редактор не запустился сам.

**Проверка:** на экране открылось окно Visual Studio Code. Приветственную вкладку можно закрыть крестиком на самой вкладке.

## Шаг 2. Установите .NET SDK

Теперь установим инструменты для создания и запуска программ.

1. Откройте [официальную страницу .NET 10](https://dotnet.microsoft.com/en-us/download/dotnet/10.0).
2. Найдите раздел **Build apps — SDK**: «Создание приложений — SDK».
3. В строке **Windows**, в столбце **Installers**, нажмите **x64** или **Arm64** — ту же архитектуру, которую определили на предыдущем шаге.
4. Скачайте установщик актуального **SDK 10.0.x**. Для этой инструкции используется стабильная версия **.NET 10 LTS** — версия с длительной поддержкой.
5. Откройте скачанный файл, нажмите **Install** и дождитесь завершения. Если Windows запросит подтверждение установки, подтвердите его.
6. После установки **закройте все окна VS Code и откройте редактор снова**. Закройте также ранее открытые отдельные окна PowerShell, если они есть.

> [!IMPORTANT]
> На странице загрузки нужен именно **SDK**. Он содержит инструменты для разработки. Раздел **Runtime** предназначен для запуска уже готовых программ; одного Runtime для создания проекта недостаточно.

Установка SDK включает среду выполнения, поэтому отдельно скачивать Runtime для нашего проекта не требуется.

**Проверка:** установщик сообщил об успешной установке. Чуть ниже мы проверим её командой в терминале.

## Шаг 3. Установите расширение C#

Расширение устанавливается **внутри VS Code**.

1. Откройте VS Code.
2. Нажмите `Ctrl + Shift + X`. Слева откроется раздел **Extensions** — «Расширения».
3. В строку поиска этого раздела вставьте:

   ```text
   @id:ms-dotnettools.csharp
   ```

4. Откройте найденное расширение **C#**. Его издатель — **Microsoft**, идентификатор — `ms-dotnettools.csharp`.
5. Нажмите **Install** — «Установить».
6. Дождитесь завершения. Если редактор предложит перезапуск, выполните его.

Для сверки: [официальная страница расширения C#](https://marketplace.visualstudio.com/items?itemName=ms-dotnettools.csharp).

**Проверка:** вместо кнопки установки доступны **Disable** — «Отключить» и **Uninstall** — «Удалить». Это означает, что расширение установлено.

> [!NOTE]
> Вместе с C# автоматически устанавливается служебное расширение **.NET Install Tool**. Оно нужно для работы расширения C#. Системный SDK, который мы установили на шаге 2, будем использовать для команд `dotnet`.

Для создания и запуска проекта по этой инструкции достаточно расширения **C#**. Дополнительный набор **C# Dev Kit** можно изучить позже.

## Шаг 4. Подготовьте папку и откройте её в VS Code

Каждую учебную программу удобно хранить в отдельной папке. Сейчас создадим общую папку для курса и внутри неё — папку первого проекта.

### Создайте папки

1. Нажмите `Win + E` — откроется Проводник Windows. `Win` — клавиша с логотипом Windows.
2. Перейдите в **Документы / Documents**.
3. Создайте папку: нажмите `Ctrl + Shift + N`, введите `CSharpCourse` и нажмите `Enter`.
4. Откройте `CSharpCourse` двойным щелчком.
5. Внутри неё таким же способом создайте папку `FirstConsoleApp`.
6. Откройте `FirstConsoleApp`. Сейчас она должна быть пустой.

Получилось такое расположение:

| Папка | Для чего |
| --- | --- |
| `Документы` | Обычное место хранения ваших файлов. |
| `Документы → CSharpCourse` | Все учебные проекты курса. |
| `Документы → CSharpCourse → FirstConsoleApp` | Только наш первый проект. |

### Откройте именно папку FirstConsoleApp

1. Переключитесь в VS Code.
2. В верхнем меню выберите **File → Open Folder…** — «Файл → Открыть папку…».
3. В открывшемся окне перейдите в **Документы → CSharpCourse → FirstConsoleApp**.
4. Нажмите **Select Folder** — «Выбор папки».
5. Если появится вопрос о доверии к содержимому, для этой пустой папки, которую вы создали сами, выберите **Yes, I trust the authors** — «Да, я доверяю авторам».

**Проверка:** слева в разделе **Explorer** — «Проводник» — видно название `FirstConsoleApp`. Оно может отображаться заглавными буквами: `FIRSTCONSOLEAPP`.

Если списка файлов слева нет, нажмите `Ctrl + Shift + E`.

### Что такое путь и как открыть папку по точному пути

**Путь** — адрес папки на компьютере. Например:

```text
C:\Users\Anna\Documents\CSharpCourse\FirstConsoleApp
```

Здесь `Anna` — пример имени пользователя. У вас будет свой путь; папка «Документы» также может находиться внутри OneDrive.

Чтобы узнать **свой** путь, откройте `FirstConsoleApp` в Проводнике, нажмите `Ctrl + L`, затем `Ctrl + C`. Адрес папки окажется в буфере обмена.

Его можно вставить в адресную строку окна **File → Open Folder…**, нажать `Enter`, а затем **Select Folder**. Так VS Code откроет папку по нужному вам адресу.

> [!TIP]
> Для работы с проектом открывайте папку, в которой лежит его файл `.csproj`. Сейчас такого файла ещё нет — мы создадим его на шаге 6.

## Шаг 5. Откройте терминал и проверьте .NET

**Терминал** — панель, в которой можно отдавать компьютеру текстовые команды.

1. В VS Code выберите **Terminal → New Terminal** — «Терминал → Создать терминал».
2. Внизу появится панель для ввода команд. Выберите профиль **PowerShell** или **Windows PowerShell**. Если открыт другой, нажмите стрелку рядом с кнопкой `+` на панели терминала и выберите PowerShell.
3. Щёлкните мышью внутри терминала, чтобы ввод попадал именно туда.

### Проверьте, в какой папке находится терминал

Введите в терминале и нажмите `Enter`:

```powershell
Get-Location
```

Команда покажет текущую папку. Её путь должен оканчиваться на:

```text
\CSharpCourse\FirstConsoleApp
```

Если путь другой, вернитесь к шагу 4, откройте `FirstConsoleApp` через **File → Open Folder…** и создайте **новый** терминал.

> [!NOTE]
> Строка вида `PS C:\Users\Anna\Documents\CSharpCourse\FirstConsoleApp>` — приглашение терминала к вводу. Её переписывать не нужно. Вводите только саму команду, например `Get-Location`.

### Проверьте установленный SDK

В этом же терминале выполните:

```powershell
dotnet --version
```

<details>
<summary>▶ Что должно получиться</summary>

Номер установленного SDK. Например:

```text
10.0.402
```

Последние цифры могут отличаться: обновления выходят регулярно.

</details>

Для проверки списка установленных SDK выполните ещё одну команду:

```powershell
dotnet --list-sdks
```

В списке должна быть строка с версией `10.0.…`. Если установлено несколько SDK, строк тоже будет несколько — это нормально.

**Проверка:** команда вывела версию SDK, а текущая папка терминала — `FirstConsoleApp`. Можно создавать проект.

## Шаг 6. Создайте консольный проект

Убедитесь, что терминал находится в пустой папке `FirstConsoleApp`.

Введите в **терминале** и нажмите `Enter`:

```powershell
dotnet new console
```

Что означает эта команда:

| Часть | Значение |
| --- | --- |
| `dotnet` | Использовать инструменты .NET. |
| `new` | Создать новый проект. |
| `console` | Выбрать шаблон консольного приложения. |

Команда создаёт проект **в текущей папке**. Мы уже назвали папку `FirstConsoleApp`, поэтому проект получит такое же имя.

Дождитесь окончания: снова появится строка, в которую можно вводить команды. При первом использовании .NET может дополнительно вывести приветствие и служебные сообщения.

<details>
<summary>▶ Что должно получиться</summary>

Появится сообщение об успешном создании консольного приложения. На английском оно выглядит примерно так:

```text
The template "Console App" was created successfully.
```

Ниже могут быть сообщения о подготовке проекта. Язык и точная формулировка зависят от установленного SDK.

В списке файлов слева появятся `Program.cs` и `FirstConsoleApp.csproj`.

</details>

### Что это за файлы

| Файл или папка | Что внутри | Что делать сейчас |
| --- | --- | --- |
| `Program.cs` | Код нашей программы. | Открывать и редактировать. |
| `FirstConsoleApp.csproj` | Настройки проекта: тип приложения, версия .NET и другие параметры. | Оставить как есть. |
| `obj` | Служебные файлы подготовки и сборки. | Они создаются автоматически. |
| `bin` | Собранная программа. Папка появится после сборки или запуска. | Она создаётся автоматически. |

**Проверка:** в открытой папке появился файл `FirstConsoleApp.csproj`. Значит, у вас теперь есть проект C#.

> [!IMPORTANT]
> Команда `dotnet new console` нужна при создании проекта. Чтобы запускать уже созданный проект, используется другая команда — `dotnet run`.

## Шаг 7. Запустите программу

1. Слева щёлкните по файлу `Program.cs`.
2. Найдите в нём строку:

   ```csharp
   Console.WriteLine("Hello, World!");
   ```

3. Щёлкните внутри **терминала** и выполните:

   ```powershell
   dotnet run
   ```

Команда соберёт проект и запустит программу. Первый запуск может занять немного времени.

<details>
<summary>▶ Что должно получиться</summary>

В терминале появится:

```text
Hello, World!
```

После этого программа завершится, и терминал снова будет готов принимать команды.

</details>

Всё сработало: вы создали и запустили консольное приложение.

## Шаг 8. Измените программу

Теперь проверим, что запускается именно тот код, который вы редактируете.

1. Откройте вкладку **Program.cs**.
2. Щёлкните внутри редактора кода.
3. Нажмите `Ctrl + A`, чтобы выделить содержимое **этого файла**.
4. Замените его двумя строками:

   ```csharp
   Console.WriteLine("My first C# program works!");
   Console.WriteLine("I am learning C#.");
   ```

5. Нажмите `Ctrl + S`, чтобы сохранить файл.
6. Щёлкните внутри **терминала** и снова выполните:

   ```powershell
   dotnet run
   ```

<details>
<summary>▶ Что должно получиться</summary>

```text
My first C# program works!
I am learning C#.
```

</details>

`Console.WriteLine` выводит текст в терминал и переходит на следующую строку. Текст сообщения записывается внутри двойных кавычек `" "`, а инструкция заканчивается точкой с запятой `;`.

Удобный порядок работы: **изменить код → сохранить файл → выполнить `dotnet run` → посмотреть результат**.

> [!TIP]
> Если на вкладке файла видна точка вместо обычного крестика закрытия, изменения ещё не сохранены. Нажмите `Ctrl + S` перед запуском.

### Маленькое самостоятельное задание

Добавьте третью строку, которая выводит ваше имя. Сохраните файл, запустите программу и проверьте, что теперь выводятся три строки.

## Как открыть этот проект в следующий раз

После закрытия VS Code файлы проекта остаются в папке на компьютере.

1. Запустите VS Code.
2. Выберите **File → Open Folder…**.
3. Откройте **Документы → CSharpCourse → FirstConsoleApp**.
4. Откройте `Program.cs`.
5. Создайте терминал: **Terminal → New Terminal**.
6. При необходимости проверьте папку командой `Get-Location`.
7. Выполните `dotnet run`.

Устанавливать SDK и расширение заново при каждом занятии не требуется. Следующий отдельный проект создавайте в новой папке внутри `CSharpCourse`.

<details>
<summary>▶ Ещё один способ: открыть папку командой code .</summary>

Этот способ пригодится, когда вы освоитесь с основными шагами.

1. Откройте нужную папку проекта в **Проводнике Windows**.
2. Нажмите `Ctrl + L`, чтобы выделить её адресную строку.
3. Введите туда `powershell` и нажмите `Enter`. Откроется окно PowerShell в этой папке.
4. В окне PowerShell выполните:

   ```powershell
   code .
   ```

Между `code` и точкой стоит **пробел**. Точка означает «текущая папка», поэтому VS Code откроет ту папку, в которой находится PowerShell.

Если команда `code` не найдена, воспользуйтесь **File → Open Folder…** и посмотрите подсказку ниже.

</details>

## Если что-то не получилось

Откройте подсказку с похожим сообщением.

<details>
<summary>▶ Терминал пишет, что команда dotnet не найдена</summary>

В PowerShell сообщение может начинаться так:

```text
dotnet : The term 'dotnet' is not recognized
```

Что сделать:

1. Проверьте, что установка **.NET SDK** на шаге 2 завершилась успешно.
2. Закройте **все** окна VS Code и PowerShell.
3. Откройте VS Code заново, откройте папку проекта и создайте новый терминал.
4. Повторите `dotnet --version`.
5. Если команда всё ещё не находится, перезагрузите компьютер и повторите проверку. Если ошибка осталась, пришлите преподавателю её полный текст.

После установки программы ранее открытые окна могут ещё не знать, где искать новую команду. Поэтому перезапуск окон — первый шаг проверки.

</details>

<details>
<summary>▶ Написано No .NET SDKs were found или список SDK пустой</summary>

Компьютер не находит инструменты разработки .NET. Например, мог быть установлен только Runtime.

Вернитесь к [шагу 2](#шаг-2-установите-net-sdk), установите **SDK** подходящей архитектуры, затем полностью перезапустите VS Code и проверьте:

```powershell
dotnet --list-sdks
```

Если в списке есть SDK, но при запуске сообщается о несовместимой версии, покажите преподавателю текст ошибки и содержимое файла `.csproj`.

</details>

<details>
<summary>▶ При запуске написано Couldn't find a project to run</summary>

Команда запускается из папки, в которой нет файла проекта `.csproj`.

1. Посмотрите текущую папку командой `Get-Location`.
2. Проверьте наличие файла проекта в ней:

   ```powershell
   Get-ChildItem *.csproj
   ```

3. Если файл не найден, откройте в VS Code папку **FirstConsoleApp**, создайте новый терминал и повторите проверку.
4. Если вы точно находитесь в нужной папке, но ещё не создавали проект, выполните [шаг 6](#шаг-6-создайте-консольный-проект).

На этом занятии команду `dotnet run` выполняем из папки с `FirstConsoleApp.csproj`.

</details>

<details>
<summary>▶ При создании проекта написано, что файлы уже существуют</summary>

Вероятно, проект уже создан или в папке лежат другие файлы.

Проверьте список файлов слева. Если `Program.cs` и `.csproj` уже есть, переходите к запуску: `dotnet run`.

Для другой учебной программы создайте **новую пустую папку**. Существующие файлы сохраняйте: повторное создание проекта поверх них может заменить ваш код.

</details>

<details>
<summary>▶ После изменения кода всё ещё выводится Hello, World!</summary>

1. Убедитесь, что изменили **Program.cs** именно открытого проекта.
2. Нажмите `Ctrl + S` внутри редактора.
3. Проверьте текущую папку терминала командой `Get-Location`.
4. Выполните `dotnet run` ещё раз.

</details>

<details>
<summary>▶ В коде появилась красная линия или программа не собирается</summary>

Сначала сравните код с примером:

- `Console` и `WriteLine` написаны с нужными заглавными буквами;
- вокруг сообщения стоят обычные двойные кавычки `" "`;
- круглые скобки открыты и закрыты;
- в конце каждой инструкции есть `;`.

Сохраните файл и повторите запуск. Если ошибка осталась, скопируйте преподавателю **первое сообщение об ошибке** из терминала и код `Program.cs`.

</details>

<details>
<summary>▶ Команда code не найдена</summary>

Для продолжения откройте проект через **File → Open Folder…**.

Чтобы заработала команда `code`, закройте и заново откройте PowerShell. Если это не помогло, повторно запустите официальный установщик VS Code и включите **Add to PATH**, если этот пункт доступен. После установки снова откройте PowerShell.

</details>

<details>
<summary>▶ Я ввёл команду в Program.cs или код программы в терминал</summary>

Ориентируйтесь по этой таблице:

| Что вводим | Куда |
| --- | --- |
| `dotnet new console` | В терминал. |
| `dotnet run` | В терминал. |
| `Get-Location` | В терминал PowerShell. |
| `Console.WriteLine("Hello!");` | В файл `Program.cs`. |

Если случайно изменили файл, отмените последнее изменение сочетанием `Ctrl + Z` внутри редактора. Затем вернитесь к нужному шагу инструкции.

</details>
